# AirBuzz

iOS app that makes a Google Fitbit Air band pulse its vibration motor when the iPhone gets a notification.
Triggered by an App Intent ("Buzz My Air") that iOS 27 Shortcuts Notification automations call.

## How the buzz works
BLE (tracker service abbaff00, TX abbaff01 write-without-response, RX abbaff02 notify) -> Gattlink -> DTLS 1.2 PSK
(public BOOTSTRAP identity) -> CoAP /settings. Changing the haptic intensity setting makes the band pulse.
After each buzz, a short session with a TLS key resolver that refuses every identity makes the band reset the link,
so Google Health gets the channel back.

## Layout
- Vendor/golden-gate: pinned Golden Gate C core (Google-Health-API fork b8a6f25, mbedtls 2.28.10), Apache 2.0. Do not edit.
- Core/: C wrapper (AB_Session) over the GG stack, plus the macOS loopback test with a fake band.
- App/: SwiftUI app, CoreBluetooth transport, App Intent. Project generated by XcodeGen (project.yml).
- scripts/check.sh: the gate (core builds for macOS and iOS, loopback test, xcodebuild).

## Rules
